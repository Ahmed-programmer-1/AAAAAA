مكتبتي V2 — مكتبة HTML + GitHub

الميزات:
- كروت المحتوى.
- الدروس متعددة الأجزاء داخل مجلد واحد.
- عند فتح الكرت تظهر الأجزاء 1، 2، 3، 4... مرتبة.
- شريط جانبي داخل المشغل للتنقل بين الأجزاء.
- السابق/التالي عبر اختيار الجزء من القائمة.
- البحث.
- التصنيفات.
- الوسوم.
- المفضلة.
- آخر ما شاهدته وسجل المشاهدة.
- المميز.
- الأكثر متابعة (محسوبة فعليًا من عدد مرات الفتح، وليست ثابتة).
- المستوى والمدة.
- الوضع الليلي.
- هوية بصرية خاصة: خط Noto Naskh Arabic للعناوين وIBM Plex Sans Arabic للواجهة (يُحمَّلان من Google Fonts، فيتطلبان اتصال إنترنت عند أول تحميل).
- PWA + Service Worker.
- صفحة تفاصيل الكورس/المجلد.
- فتح في تبويب جديد.
- ملء الشاشة.
- Admin مخفي بدون رابط من الموقع العام.
- رفع وتعديل وحذف المحتوى مباشرة عبر GitHub Contents API.
- رفع عدة ملفات HTML للدرس الواحد وترتيبها بالأرقام.
- حفظ الملفات داخل:
  courses/<id>/part-01.html
  courses/<id>/part-02.html
  ...
  courses/<id>/cover.png

استثناءات بناءً على طلب المشروع:
- لا يوجد نظام تقدم بالنسبة المئوية.
- لا توجد صفحة/علامة "الدروس المكتملة".

إعداد GitHub:
1. Fine-grained Personal Access Token.
2. Repository access: المستودع المطلوب فقط.
3. Repository permissions: Contents = Read and write.
4. افتح admin.html مباشرة.
5. Owner = اسم حساب GitHub.
6. Repository = اسم المستودع.
7. Branch = main غالبًا.

ملاحظة أمنية:
admin.html مخفية عن المستخدمين، لكن إخفاء الرابط ليس مصادقة حقيقية. الـToken لا يوضع في المستودع ويُحفظ في sessionStorage فقط. للحماية الفعلية من شخص يعرف رابط admin.html، استخدم Backend/Cloudflare Worker يحتفظ بالـToken على الخادم.
